# דוח בדיקות ומסירה

## נתונים

| מקור | הודעות | קובצי מדיה שהועתקו | קבצים לא משויכים |
|---|---:|---:|---:|
| Snapchat, הצ'אט `myrb_bnkhyy2020` | 68,453 | 233 | 202 |
| WhatsApp | 83,302 | 1,036 | 0 |

קובצי המדיה הלא משויכים של Snapchat נשמרו באתר ולא נמחקו. הם מופיעים ב־`data/unmatched-media.json`, משום שלרובם אין `Media IDs` שניתן לקשור להודעה מסוימת באופן חד־משמעי.

## בדיקות שעברו

- `node --check js/app.js`
- `node tools/check_data.mjs`
- `python3 -m py_compile tools/build_data.py`
- בדיקת `manus-routes.json` כ־JSON תקין.
- בדיקת HTTP 200 עבור `/`, קובצי הנתונים, CSS, JavaScript ו־`manus-routes.json`.
- בדיקת זהות מלאה בין `index.html` ו־`index.htm`.
- בדיקת סדר כרונולוגי בכל הודעות Snapchat ו־WhatsApp.

## מגבלת GitHub

האתר כולו הוא כ־900 MB. ארבעה סרטוני WhatsApp חורגים ממגבלת 100 MB לקובץ של GitHub: `VID-20261022-WA0069.mp4`, `VID-20261022-WA0068.mp4`, `VID-20261022-WA0087.mp4`, `VID-20261022-WA0088.mp4`. הם נשמרו בחבילת המסירה. לפרסום כל המדיה ב־GitHub יש להשתמש ב־Git LFS או באחסון קבצים סטטי חיצוני.
