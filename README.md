# שיחות הילה — Snapchat ו-WhatsApp

זהו אתר סטטי שמציג את ייצוא השיחות האמיתיים שסופקו. אין כאן הודעות דוגמה: הנתונים נבנו מקובץ Snapchat ומייצוא WhatsApp המקורי, והאתר טוען אותם מקומית מהתיקיות `data/` ו־`media/`.

## הפעלה מקומית

מתיקיית הפרויקט אפשר להפעיל שרת סטטי פשוט:

```bash
python3 -m http.server 3000
```

לאחר מכן לפתוח בדפדפן את `http://localhost:3000`. אין לפתוח את `index.html` ישירות דרך `file://`, כי הדפדפן יחסום טעינת JSON.

## העלאה ל-GitHub Pages

יוצרים Repository חדש ומעלים את כל מבנה התיקיות, לא רק את `index.html`: את `css/`, `js/`, `data/` ו־`media/` יחד עם הקובץ הראשי. ב־Settings → Pages בוחרים את הענף ואת תיקיית השורש. האתר מוכן לעבוד ללא שרת וללא Build Step.

חשוב: בייצוא WhatsApp יש סרטונים הגדולים ממגבלת GitHub של 100 MB לקובץ. GitHub Pages רגיל לא יקבל אותם. הדוח `data/manifest.json` מזהה את המדיה הגדולה; כדי לפרסם את כל המדיה צריך Git LFS או אחסון קבצים סטטי חיצוני ולעדכן את הנתיבים. אין למחוק אותם אם רוצים לשמור את הייצוא המלא.

## בנייה מחדש מהייצואים

הכלי הדטרמיניסטי נמצא ב־`tools/build_data.py` והוא אינו משתמש ברשת או ב־AI:

```bash
python3 tools/build_data.py \
  --snapchat /path/Snapchat-hila-141126.zpi \
  --whatsapp "/path/צ'אטWhatsAppעםהילה❤️14.11-1918" \
  --out .
```

הוא מפיק את כל 68,453 הודעות Snapchat מהצ'אט שנבחר ואת כל הודעות WhatsApp, מעתיק וממפה קבצים לפי שם ומפיק `data/manifest.json` עם חריגים. אם ייצוא WhatsApp חדש מכיל רק TXT ו־VCF, הכלי משלב את הטקסט החדש עם מדיה שכבר נמצאת ב־`media/whatsapp/`.

## פרטיות

בהתאם לבקשה האחרונה, האתר נשמר במצב גלוי וללא שכבת הצפנה. כל מי שמקבל גישה ל־Repository או ל־GitHub Pages יכול לקרוא את הנתונים ואת המדיה. אם משנים החלטה זו, יש להוסיף שלב הצפנה מקומי לפני העלאה ולא לפרסם את קובצי המקור הגלויים.
